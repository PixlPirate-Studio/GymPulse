# GymPulse API (v1)

Base: `https://YOUR-SERVER/api/v1/` (`/api/...` without `v1` is the same thing). All bodies are JSON. Errors look like `{"error": "Plain-English message"}` with a normal HTTP status.

The complete, always-current list of routes is generated by the server at **`GET /api/v1/openapi.json`**. Use that as the reference; this page covers the ideas.

## Sign in
| Call | Notes |
|---|---|
| `GET /server` | Public. Server name, `api_version`, `features`, `needs_setup`. |
| `POST /auth/token` | `{username,password,device_name}` or `{code,device_name}` returns `{token,user}`. Rate limited. |
| `POST /auth/pair` | Signed in. Returns a code good for 5 minutes. |
| `POST /auth/revoke` | Turns off the calling token. |
| `GET/POST/DELETE /tokens` | List, create (`scope` `full` or `health`), remove. |
| `GET /invite/<t>` / `POST /invite/<t>/accept` | Public sign-up from an invite link. |

Send `Authorization: Bearer gp_...` on everything else.

## Workouts
- `GET /routine`, `POST /routine`, plan endpoints: the saved workouts.
- `POST /sync/workout`: send a whole workout. Body:
  `{cid, plan, date:"YYYY-MM-DD", started_at, ended_at?, paused_sec?, exercises:[{cid, name, kind:"sets"|"timed", sets_total, sets_done, completed, seconds, reps, category, note, sets:[{set_no, weight_lb, reps}]}]}`
  Send again with more data any time. Include `ended_at` to finish it. Personal bests and badges are worked out by the server.
- `GET /exercise-history?name=` (last time + best), `GET /records`, `GET /exercise-guide[?name=]`.
- The older step-by-step calls (`/session/start`, `/session/<id>/exercise/<id>`, `/session/<id>/finish`) still work.

## Food and body
`/diary`, `/diary/copy`, `/foods/search`, `/foods/barcode/<code>`, `/meals`, `/water`, `/measurements`, `/weight`, `/grocery`, `/recipes`, `/photos` (multipart field `photo`), `/health` (POST steps etc. with a `health` or `full` token).

## Friends
`/friends`, `/leaderboard`, `/feed`, `/feed/<id>/react {emoji}`, `/friends/<id>/nudge`, `/challenges`, `/badges`, `/notifications`, `/reminders`.

## Units
Weights are pounds, heights are inches, distances are miles, water is ounces.

## Retries
Add `Idempotency-Key: <random string>` to any non-GET call to make retries safe.
